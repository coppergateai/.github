# Security

If you believe you have found a security issue in Coppergate or any repository under [coppergateai](https://github.com/coppergateai), email **[hello@coppergate.ai](mailto:hello@coppergate.ai)** with “Security” in the subject line.

Please include enough detail to reproduce the issue. Do not open a public GitHub issue for vulnerabilities.

We aim to acknowledge reports within a few business days.
