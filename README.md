# coppergateai/.github

Organization profile and shared GitHub metadata for [coppergateai](https://github.com/coppergateai).

## Layout

| Path | Purpose |
|------|---------|
| [`profile/README.md`](./profile/README.md) | Public org homepage (Overview tab) |
| [`profile/og.png`](./profile/og.png) | Banner for the org profile |
| [`profile/avatar.png`](./profile/avatar.png) | Org avatar master (upload in org settings) |
| [`profile/logo*.svg`](./profile/) | Mark / lockup copies for profile media |
| [`SECURITY.md`](./SECURITY.md) | Security contact for the organization |

Brand masters live in [`coppergate-architecture/brand`](https://github.com/coppergateai/coppergate-architecture/tree/main/brand). Visual rules: [`BRAND.md`](https://github.com/coppergateai/coppergate-architecture/blob/main/docs/BRAND.md).

## Updating the org profile

1. Edit `profile/README.md`.
2. Keep banner and lockup assets in sync with `coppergate-architecture/brand` when those masters change.
3. Push to `main` — GitHub renders the Overview from `profile/README.md` automatically.

## Org settings checklist

- **Avatar:** upload `profile/avatar.png` (white mark on `#0A0A0A`)
- **Website:** `https://coppergate.ai`
- **Email:** `hello@coppergate.ai`
- **Pinned repos:** `coppergate`, `coppergate-architecture`, `coppergate-examples`
